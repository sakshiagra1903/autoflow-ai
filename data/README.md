# Data provenance

The CSV files bundled here are **synthetic demonstration data generated for software testing**. They are not official UN Comtrade, World Bank, or DGCIS records and must not be used as factual import statistics.

- `sample_trade_monthly.csv`: monthly commodity/partner import value and quantity.
- `sample_commodity_prices.csv`: monthly reference-price-like series with consistent demo units.
- `evidence_sources.json`: reference links for future ingestion; these are not dated evidence of a disruption.

For production research, replace the demo files with licensed, retrieved records and preserve source URL, publication date, data period, retrieval timestamp, units, and revision notes per record.
